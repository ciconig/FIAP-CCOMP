# FIAP-CCOMP

Repositório do Curso de Ciência da Computação da FIAP.

## 📋 Objetivo

Este repositório armazena todas as atividades e projetos desenvolvidos durante todo o curso de Computação, organizados por fases.

## 📁 Estrutura do Repositório

A organização segue um padrão de pastas por período/fase do curso:

```
FIAP-CCOMP/
├── 1CCOMP/                        # Pasta do primeiro ano do curso
│   ├── FASE1-ATIVIDADE/
│   │   ├── README.md              # Descrição das atividades da fase
│   │   ├── requirements.txt       # Dependências do projeto
│   │   ├── simulador_decolagem.ipynb  # Notebook com implementação
│   │   └── prints/                # Prints das execuções e resultados
│   │
│   ├── FASE2-ATIVIDADE/          # (Próximas fases)
│   └── FASE3-ATIVIDADE/          # (Estrutura similar)
│
└── README.md                      # Este arquivo
```

## 🎯 Como Usar

Cada pasta de fase (`FASEXX-ATIVIDADE`) contém:

- **README.md**: Documentação detalhada das atividades
- **Notebooks e Scripts**: Implementações das soluções
- **requirements.txt**: Dependências do projeto (se aplicável)
- **prints/**: Screenshots e outputs das execuções

## 📚 Fases do Curso

### Fase 1 (1CCOMP)
A atividade consiste em elaborar um Relatório Operacional de Pré-Decolagem da nave AURORA. O grupo deverá interpretar dados de telemetria, definir critérios de segurança e implementar uma solução que determine se a nave está “PRONTA PARA DECOLAR” ou se a “DECOLAGEM DEVE SER ABORTADA”.⁠
